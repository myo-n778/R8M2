# M2/H2共通 AI解説GAS（ローカル準備）

通常の解説の下から任意で「AI解説を見る」を開きます。正解の理由／選んだ答えとの違い、やさしい説明、300文字までの自由質問に対応します。採点・成績保存用GASとは独立しています。

## 公開時の設定（今回未実施）

1. M2/H2共通のAI用Apps Scriptプロジェクトを1つ作り、`Code.gs` を配置します。既存の成績GASや化学アプリのGASへ混ぜないでください。ファイルはM2側で正本管理していますが、内容は共通です。
2. スクリプトプロパティに `OPENAI_API_KEY`、`SCIENCE_AI_ENABLED=true`、`SCIENCE_AI_M2_SHEETS`、`SCIENCE_AI_H2_SHEETS` を設定します。後ろ2つは各アプリで許可する15列教材シート名のJSON配列です。例: `["4-1電気"]`。実在の教材名を確認し、成績・名簿・設定シートを指定しないでください。空欄・空配列のアプリは利用できません。
3. 設定したモデルの利用可否、両教材の読取権限、API側の支出制限を確認してからウェブアプリとしてデプロイします。M2とH2それぞれの `common/ai-tutor.js` の `ENDPOINT` に同じ共通URLを設定します。APIキーはブラウザへ配置しません。
4. 明示承認のある範囲で実APIと実教材を検証した後、フロントを公開します。現在はURL空欄のため課金APIを呼びません。

教材はGAS内 `SCIENCE_AI_APPS` に登録したM2/H2の固定スプレッドシートから読取のみ。ブラウザから任意のシートIDや説明指示を渡して切り替えることはできません。アプリID・画面のID・単元・問題・4択・正解・解説をSHA-256で照合します。15列以外は対象外です。画像の内容は送信せず、画像が必要なら推測を避けて確認を促す指示です。氏名・クラス・成績はリクエストに含めません。自由入力に個人情報を書かないよう画面で案内します。

## M2とH2の切替

- `appId: "m2"` は中学2年理科、`appId: "h2"` は高校2年物理。固定教材IDは各アプリの現行HTMLと照合済みです。
- `session` と `answer` の両操作で `appId` が必須です。`answer.mode` も同じ値とします。セッションは生成時のアプリに固定し、他方への転用は拒否します。
- 通信版は `science-sheets-v2`。署名対象は `JSON.stringify([appId,q.id,q.era,q.question,q.options,q.answer,q.explanation])` のSHA-256です。
- M2・H2両方の画面にパネルを組込み済みです。同じJS/CSSを使用し、`APP_ID` だけをM2は `m2`、H2は `h2` とします。回答後のmountと次問・ホーム・終了・ログアウトのreset/logoutを接続しています。ログアウトを取り消した場合は状態を維持します。既存エクスポート名 `M2AiTutor` は画面互換のため維持しています。
- M2は `R8M2/science2.0.html` と配布用 `R8M2_repo/problemset/`、H2は `../H2/R8H2_repo/problemset/physics2.0.html` と同階層の `common/ai-tutor.js` / `ai-tutor.css` が更新対象です。GASだけでなくHTMLとJS/CSSも公開する必要があります。現在は両画面ともURL未設定・未公開です。
- 旧M2専用版の `M2_AI_ENABLED` / `M2_AI_SHEETS` と旧通信版は使用しません。まだ未公開のため旧状態の自動移行はありません。

## 上限と失敗時

- 1問3回、2時間の匿名利用セッション20回。アプリごとにセッション・問題回数・会話履歴・日次回数を分離します。アプリ別日次上限も30回ですが、費用上限を増やさないためM2/H2全利用者合計1日30回（日本時間）を同時に適用します。一方の利用で合計上限に達すれば他方も停止します。
- ページ再読込で新しい匿名セッションになります。アプリIDは教材切替用であり個人認証ではありません。生徒ごとの厳密な日次制限ではありません。
- 同時API呼出し1件。回数はAPI呼出し前に確保し、失敗やキャンセルでも消費します。同じリクエストIDは再課金しません。
- ブラウザは30秒で待機終了し、自動再送しません。送信後の通信状態が不明なら、そのページ内の追加送信を停止します。ブラウザの待機終了はGAS/APIの処理停止を保証しません。
- 公開エンドポイントはログイン認証では保護されません。外部利用で共通枠を消費されるリスクがあり、全体上限が費用防止の主な制御です。
- API送信時は `store:false`。同一問題の直近2往復はGASキャッシュに最大2時間、リクエスト結果と匿名回数はプロパティに有効期限付きで保持し、期限切れは次回セッション生成時に削除します。氏名などは保存しませんが自由質問の本文は含まれます。

## 生成・検査

`node gas-ai/build.mjs` で `Code.gs` を再生成します。テンプレートは化学アプリのロック・回数予約・重複防止方式を移植し、教材読取と指示をM2/H2共通化しました。化学側のソースは変更していません。モデルは参照元と同じ `gpt-5.6-luna` を初期値として継承しており、実APIでの利用可否は未確認です。

`node gas-ai/tutor.test.mjs` はGAS環境とAPIを完全に模擬し、有料APIを呼びません。`H2_HTML` 環境変数にH2正本HTMLのパスを指定すると、H2の実パーサーとの一致も検査します。M2作業ルートでの検査例:

```sh
H2_HTML='../H2/R8H2_repo/problemset/physics2.0.html' node R8M2/gas-ai/tutor.test.mjs
```

ブラウザ検査は `R8M2/tests/ai-tutor-browser.cjs`。Playwrightを用意し、M2は既定値で実行、H2は `AI_APP_ROOT=../H2/R8H2_repo/problemset AI_APP_ID=h2 AI_APP_HTML=physics2.0.html` を指定します。通信は模擬し、両画面の実採点・パネル・遷移・ログアウト・幅を検査します。実APIと本番確認は別工程です。
